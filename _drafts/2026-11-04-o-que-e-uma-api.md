**Rascunho de exemplo para a prévia do site (texto a revisar antes de publicar).**

Imagine um restaurante. Você (o aplicativo) não entra na cozinha (o sistema de outra empresa): você fala com o garçom, faz o pedido do jeito que o cardápio permite e recebe o prato. **A API é o garçom e o cardápio**: o jeito combinado de um programa pedir coisas a outro.

Por exemplo, um app de clima não mede a temperatura: ele pergunta a um serviço de meteorologia por uma API e mostra a resposta.

**Onde ir depois:** procure a documentação da API de um serviço que você usa e leia só a parte "primeira requisição". Manda a próxima pergunta na caixa de perguntas!
